# CSVエディター 現行機能一覧

対象は、ブラウザで動く `csv_editor_app`。画面・動作条件は現行のソースコードを基に記載している。

## 機能一覧

| 機能ID | 機能 | 現行の動作・条件 |
|---|---|---|
| F01 | 初期データ読み込み | 起動時に行追加テンプレートを読み込み、その後に交通費精算用の初期CSVを開く。同梱のJSONは2ファイル。起動時のテンプレート読み込みで有効なテンプレートを取得できなければ、内蔵テンプレートを使う。初期CSVを取得できない場合はファイル選択から作業を始められる。 |
| F02 | ファイル読み込み | ファイル選択で `.csv`、`.tsv`、`.txt` を開く。空の表に表示される領域ではドラッグ＆ドロップも使える。UTF-8、UTF-8 BOM付き、Shift_JISに対応し、先頭行を列名として扱う。 |
| F03 | セル・列名の編集 | セル・行・列を選択できる。セルはダブルクリックまたは選択後のEnterで編集を開始し、Enterまたはフォーカスを外す操作で確定する。Tabでは確定後に次のセルを選択し、Escでは編集を取り消す。日本語変換中のEnterは確定に使わない。列名はヘッダーの入力欄から変更する。 |
| F04 | 行・列の追加 | 空行を選択行の下、空列を選択列の右に追加する。対象となる行・列の選択がなければ、それぞれ末尾に追加する。 |
| F05 | 検索 | 表のセルを対象に、大文字・小文字を区別せず部分一致を強調表示する。表には一致しない行も表示される。 |
| F06 | 列の一括編集 | 対象列の全行に対して、固定値入力、文字列置換、連番、接頭辞・接尾辞の追加、大文字・小文字変換、前後の空白除去、四則演算を実行できる。文字列置換は一致したセル、四則演算は数値として読み取れるセルが対象。 |
| F07 | テンプレートによる複数行追加 | テンプレートと開始日・終了日を指定し、両端を含めて1日1行、最大1,000日分を追加する。選択行の直後、または末尾に挿入する。既存の表には `日付` 列が必要。テンプレート項目名と列名が一致したセルに値を入れ、未一致項目があれば通知する。 |
| F08 | テンプレート管理 | テンプレートの作成・編集・削除、項目の追加・削除、JSONの読み込みと書き出しができる。画面での保存は開いているページに反映される。JSONを読み込むと一覧全体を置き換える。 |
| F09 | 表の初期化 | 空の表を新規作成する、内蔵サンプルデータを表示する、確認後に表を全消去する。空の表は4列×3データ行。 |
| F10 | 元に戻す・やり直す | 列名と表データの履歴を最大30件保持する。ツールバーのボタン、または入力欄の操作中を除き、Ctrl／CommandとZ・Yなどのショートカットで操作できる。 |
| F11 | CSV／TSV書き出し | 出力ファイル名、区切り文字（カンマ／タブ）、文字コード（UTF-8 BOM付き／UTF-8 BOMなし／Shift_JIS）を選び、列名とデータをダウンロードする。出力には少なくとも1列が必要。 |
