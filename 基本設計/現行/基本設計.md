# CSVエディター 現行基本設計

## システム構成

`web_csv_editor.html` に画面・スタイル・編集処理をまとめたブラウザアプリ。READMEでは、VS CodeのLive Serverでディレクトリを配信し、ブラウザから開く手順を案内している。HTMLは同じ配信元にある初期CSVとテンプレートJSONを `fetch()` で取得する。利用者が選んだファイルはブラウザで読み込み、出力データはブラウザからダウンロードする。

外部ライブラリはHTTPSのCDNから読み込む。Tailwind CSSは画面スタイル、Lucideはアイコン、PapaParseは区切り付きテキストの解析と生成、encoding-japaneseはShift_JISでの書き出しを担当する。

## 画面構成

| 画面・領域 | 主な表示と操作 | 機能ID |
|---|---|---|
| 編集画面 | 上部の操作ボタンと検索欄、列名と明細の表、行・列数、下部のステータスを表示する。 | F01〜F06、F09〜F11 |
| ファイル選択・ドロップ領域 | 表が空のときに表示する。ファイル選択、ドロップ、空の表の作成、サンプル表示ができる。 | F02、F09 |
| 一括編集ダイアログ | 対象列を選び、編集方式ごとに値や演算条件を入力する。 | F06 |
| 複数行追加ダイアログ | テンプレート、開始日、終了日を指定する。 | F07 |
| テンプレート管理ダイアログ | テンプレート名と項目・値を編集し、保存、削除、JSON入出力を行う。 | F08 |
| 書き出しダイアログ | 出力ファイル名、文字コード、区切り文字を指定する。 | F11 |

## データ構成と保持

| データ | 形式と扱い |
|---|---|
| 初期CSV | `交通費精算_申請データテンプレート.csv`。ヘッダーは `日付,出発,到着,往復,金額/Km,客先請求,申請理由,交通機関,備考`。起動時に通常のファイル読み込みと同じ処理へ渡す。 |
| 行追加テンプレート | `json/row_templates.json` と `json/row_templates2.json` に各1件を同梱する。JSONのトップレベルは `version` と `templates`。各テンプレートの `name` は表示名、`values` は列名と入力値の組、`id` は識別子で、省略時はアプリが生成する。 |
| 表データ | 列名と行データをブラウザ内の配列として保持する。先頭行を列名に使い、空の列名は `列 A` などで補う。 |
| 編集状態と履歴 | 選択中のセル・行・列、編集中のセル、検出した文字コードをページ内に保持する。履歴に保存するのは列名と行データで、最大30件。 |
| 画面で編集したテンプレート | 現在のページ内の一覧に反映する。次回利用や共有に使うファイルは、テンプレート管理からJSONとして書き出す。 |
| 同梱の入力ルール資料 | `交通費精算_入力ルール.csv`。調査した現行HTMLからの読み込み・参照は確認できていない。 |

## 主な処理

| 処理 | 現行設計 |
|---|---|
| 起動 | 既知のJSON 2ファイルと、ディレクトリの一覧から取得できたJSONファイルを読み込む。有効なテンプレートをまとめ、同一IDが複数ある場合は、読み込み対象の順で最初に現れた定義を使う。その後、初期CSVを取得する。 |
| ファイル読み込み | 先頭のBOMを調べ、BOMがなければUTF-8での厳密なデコードを試す。失敗した場合にShift_JISとしてデコードする。PapaParseで区切り文字を判定し、空行を除いて先頭行と明細に分ける。 |
| 表の更新 | 列名・明細・選択状態から表を描画し、検索語に一致するセルを強調する。セル編集の確定時は対象セルの値を更新する。 |
| 期間指定の行生成 | 開始日から終了日までの日付を `YYYY-MM-DD` 形式で `日付` 列に入れる。テンプレート値は列名との完全一致で設定し、値が割り当てられない列は空欄にする。列が一つもない場合はテンプレートの項目名から列を作る。 |
| ファイル書き出し | 列名と行データを並べ、選択された区切り文字でテキストに変換する。BOM付与またはShift_JIS変換を必要に応じて行い、指定されたファイル名でダウンロードする。 |

## エラー時の動作

| 条件 | 画面・処理の動作 |
|---|---|
| 起動時に有効なテンプレートを取得できない | 内蔵テンプレートを使用する。 |
| 初期CSVを取得できない | ファイルを選択できる状態にし、画面下部に案内を表示する。 |
| テンプレートJSONが不正、またはテンプレートが空 | メッセージを表示し、読み込み前の一覧を保持する。 |
| 複数行追加のテンプレート未選択、日付未入力・逆順、上限超過、既存の表に `日付` 列がない | メッセージを表示し、追加を中止する。 |
| Shift_JISの変換ライブラリが読み込まれていない状態でShift_JIS出力を選択 | メッセージを表示し、ダウンロードを中止する。 |

## 画面表示と実装の差異

画面下部には「Enter: 下移動」と表示される。実装では、編集中のEnterは入力を確定し、同じセルを選択した状態にする。
