# 解答用紙GAS 操作手順

## 1. 最新のコードを反映する

1. ターミナルでプロジェクトのディレクトリに移動します。

   ```bash
   cd /Users/sawauchiryouta/00_ObsidianMemo/Vault/10_private-dev/create-answer-paper-gas
   ```

2. 次のコマンドを実行します。

   ```bash
   npx @google/clasp push
   ```

3. 対象のスプレッドシートを再読み込みし、上部に「パーツ編集」メニューが表示されることを確認します。
4. 初回実行時に権限の確認が表示されたら、内容を確認して承認します。標準の Google Cloud プロジェクトを使っている場合は、Google Cloud 側で Sheets API の有効化も必要です。

## 2. 試験用のシートを用意する

1. 試験ごとにひな形のスプレッドシートをコピーします。
2. 「出力」「基本パーツ」シートがあることを確認します。ない場合は Apps Script エディタから `setupSheets` を実行します。
   新規に「出力」を作成した場合は、考査見出し・得点枠・年組氏名欄が自動で配置されます。得点枠の左上は AZ44、年組氏名欄の左上は AZ48 です。既存の「出力」には追加されません。
   「出力」がなく、以前の作業データが残っている場合は、管理情報の上書きを避けるためセットアップを中止します。
3. 以前の「設定」シートがある場合は、そのまま残せます。設定保存の操作は不要です。

## 3. 問題文から大問を追加する

1. 「出力」シートを開き、「パーツ編集」→「パネルを開く」を選びます。
2. 「問題文から作成」に問題文を貼り付けます。大問見出しがない場合は大問番号も入力します。
3. 小問ごとに分ける場合は、`(1)` や `(2)` を各行の先頭に置きます。「小問を解析」を押し、大問と小問、解答欄のプレビューを確認します。
4. 必要な大問にチェックを入れ、「要確認」の項目を確認します。
5. 「選んだ大問を出力に配置」を押し、候補のセル範囲を確認します。位置を変えるときや自動で空きが見つからないときは、左上のセル番地を入力します。シートで指定する場合は、「出力」上でセルを１つ選び、「シートで選択したセルを取得」を押します。
6. 手動で指定した場合は「指定位置を確認」を押します。既存の内容と重なる場合や用紙に収まらない場合は、別の位置を指定します。
7. 表示された範囲でよければ「この位置に配置」を押します。確定時に出力が変わっていた場合は、候補を確認し直します。
8. 10秒以上かかる案内が出たら、その画面で結果を待ちます。完了時に配置の応答時間が表示されます。目標は3.5秒です。

## 4. 基本パーツを追加・編集する

1. 追加が必要な場合は「基本パーツ」タブから考査見出し・年組氏名欄・得点枠を選び、「出力に追加」を押して、表示された配置候補を確認します。
   初回追加時、得点枠は AZ44、氏名欄は AZ48 を左上として配置されます。AZ列から用紙右端のBT列までは21列のため、それより広い設定は21列に調整します。配置先に内容がある場合や用紙内に収まらない場合は、上書きせずに操作を中止します。
2. 「手動で作成・編集」タブで、追加済みのパーツの幅、高さ、順番などを編集できます。
3. シート上で直接変更したパーツをパネルでも変更しようとすると、内容を上書きしないよう操作が止まり、対象範囲が表示されます。
4. 旧バージョンで作成されたパーツは、直接編集の有無を判別できないため、パネルでの変更を止めます。出力上の既存内容は保持され、新しいパーツは空き領域へ追加できます。

## 5. 配置済みのパーツを削除する

1. 「出力」シートで、削除したい大問の見出しや解答欄、または基本パーツの中のセルを１つ選びます。「手動で作成・編集」で「配置済みパーツを削除」を押します。パネルの一覧は、登録解除など対象を選ぶ別の操作で使います。
2. 「パーツの削除」ダイアログでパーツ名と現在の範囲を確認し、「削除」を押します。行を挿入して位置がずれた場合でも、パーツ全体が登録時の状態と一致すれば削除できます。候補が見つからない場合や複数ある場合は、別のセルを選び直します。ダイアログが開いている間は背後のシートを操作できません。
3. 完了と応答時間が表示されたら「閉じる」を押します。パーツ一覧は自動更新されます。10秒以上かかる案内が出た場合は結果を待ちます。
4. 確定前に右上の「×」で閉じた場合は、パーツ編集画面に「確認画面を閉じた場合はこちら」が表示されたら押して確認を取り消せます。処理開始後に「×」で閉じるとシートは操作できますが、削除処理は続き、パーツ編集の操作は結果確認まで待機します。
5. 出力を直接編集・削除したため登録内容と一致しない場合は、「変更済みパーツの登録を解除」で対象と範囲を確認します。解除するのは作業データの登録だけで、出力セルには手を加えません。

> セルから削除対象を特定する方式と、確認を開くまでの黒いオーバーレイを外した修正は、ローカルに反映済みです。Apps Script で使用するには、これらの修正を反映してください。

## 6. 別シートで仕上げる

1. パーツの配置が終わったら、「出力」シートのタブを右クリックし、「複製」を選びます。
2. 複製したシートで文字、枠線、位置などを細かく調整します。パーツ編集の操作は「出力」シートを対象にするため、複製先の仕上げを維持できます。

## 7. 印刷する

1. 仕上げたシートの `A1:BT51` を選択します。
2. 印刷設定で B4、横向き、1ページに合わせて印刷します。
3. 印刷プレビューで文字、枠線、余白を確認します。行の高さや列幅はシートで調整できます。
