# 解答用紙GAS 操作手順

> この手順は現在のローカル実装に対応します。「配置データ」の表示と新規出力時の基本パーツ設定を利用するには、最新コードの反映が必要です。

## 1. 最新のコードを反映する

1. ターミナルでプロジェクトのディレクトリに移動します。

   ```bash
   cd /Users/sawauchiryouta/00_ObsidianMemo/Vault/10_private-dev/create-answer-paper-gas
   ```

2. 次のコマンドを実行します。

   ```bash
   npx @google/clasp push
   ```

3. 対象のスプレッドシートを再読み込みし、上部に「パーツ編集」メニューが表示されることを確認します。
4. 初回実行時に権限の確認が表示されたら、内容を確認して承認します。標準の Google Cloud プロジェクトを使っている場合は、Google Cloud 側で Sheets API の有効化も必要です。

## 2. 試験用のシートを用意する

1. 試験ごとにひな形のスプレッドシートをコピーします。
2. 「出力」「基本パーツ」シートがあることを確認します。ない場合は Apps Script エディタから `setupSheets` を実行します。
3. 新規に「出力」を作成すると、「基本パーツ」の配置セル・表示文字・幅・高さ・後の空き行を読み取り、考査見出し・得点枠・年組氏名欄を配置します。
4. パーツ編集などでデータが読み込まれると、配置情報を保存する「配置データ」シートが表示されます。

## 3. 問題文から大問を追加する

1. 「出力」シートを開き、「パーツ編集」→「パネルを開く」を選びます。
2. 「問題文から作成」に問題文を貼り付けます。大問見出しがない場合は大問番号も入力します。
3. 小問ごとに分ける場合は、`(1)` や `(2)` を各行の先頭に置きます。「小問を解析」を押し、大問と小問、解答欄のプレビューを確認します。
4. 必要な大問にチェックを入れ、「要確認」の項目を確認します。希望位置がある場合は「配置の左上セル」に番地を入力するか、「出力」上の単一セルを選んで「シートで選択したセルを取得」を押します。
5. 「選んだ大問を出力に配置」を押し、候補のセル範囲を確認します。空欄の大問は前の大問と「後の空き（行）」をもとに候補が出ます。たとえば大問3が `C12:AI16` で空きが2行なら、空いている場合は大問4の左上候補が `C19` です。
6. 候補を変える場合は「位置を変更」から左上の番地を入力し、「指定位置を確認」を押します。重なりや用紙外の表示が出たら、別の位置を指定します。自動で候補を出したい大問は空欄にできます。
7. 表示された範囲でよければ「この位置に配置」を押します。確定時に出力が変わっていた場合は、候補を確認し直します。

## 4. 基本パーツを追加・編集する

1. 初期候補を指定する場合は「基本パーツ」シートの B列「配置の左上セル」に番地を入力します。空欄と旧形式の数値は自動候補を使います。パーツ編集の「基本パーツ」タブで、考査見出し・年組氏名欄・得点枠のいずれかの「出力に追加」を押し、表示された候補範囲を確認します。
2. 位置を変える場合は「位置を変更」を押します。自動で空きが見つからない場合は位置入力が表示されます。左上の番地を入力するか、「出力」でセルを１つ選び、「シートで選択したセルを取得」を押します。
3. 「指定位置を確認」を押します。手動指定ではひな形の幅を使います。既存の内容と重なる場合や用紙に収まらない場合は、別の位置を指定します。
4. 表示された範囲でよければ「この位置に配置」を押します。確定前に配置先が埋まった場合は、候補を確認し直します。「キャンセル」で追加を取り消せます。
5. 配置済みの基本パーツや大問を移動するときは、「手動で作成・編集」で対象を選び、「配置の左上セル」を変更します。「変更内容を確認」で移動前と移動後の範囲を確認し、「変更を出力に反映」を押します。出力を直接編集したため登録時の状態と一致しない場合は、アプリからの変更が止まります。

## 5. 配置済みのパーツを削除する

1. 「出力」シートで、削除したい大問の見出しや解答欄、または基本パーツの中のセルを１つ選びます。「手動で作成・編集」で「配置済みパーツを削除」を押します。パネルの一覧は、登録解除など対象を選ぶ別の操作で使います。
2. 「パーツの削除」ダイアログでパーツ名と現在の範囲を確認し、「削除」を押します。行を挿入して位置がずれた場合でも、パーツ全体が登録時の状態と一致すれば削除できます。候補が見つからない場合や複数ある場合は、別のセルを選び直します。ダイアログが開いている間は背後のシートを操作できません。
3. 完了と応答時間が表示されたら「閉じる」を押します。パーツ一覧は自動更新されます。10秒以上かかる案内が出た場合は結果を待ちます。
4. 出力を直接編集・削除したため登録内容と一致しない場合は、「変更済みパーツの登録を解除」で対象と範囲を確認します。解除するのは「配置データ」の登録だけで、出力セルには手を加えません。

## 6. 別シートで仕上げて印刷する

1. パーツの配置が終わったら、「出力」シートのタブを右クリックし、「複製」を選びます。
2. 複製したシートで文字、枠線、位置などを細かく調整します。パーツ編集の操作は「出力」シートを対象にするため、複製先の仕上げを維持できます。

3. 仕上げたシートの `A1:BT51` を選択します。
4. 印刷設定で B4、横向き、1ページに合わせて印刷します。
5. 印刷プレビューで文字、枠線、余白を確認します。行の高さや列幅はシートで調整できます。

## 7. 注意点

-

- 「出力」がなく配置情報が残っている場合は、セットアップを中止します。配置データと出力の状態を確認してください。
- 新規出力時に基本パーツの指定範囲が重なる場合や用紙外の場合は作成を中止します。基本パーツの設定を修正して再実行してください。
- 基本パーツの配置セルが空欄または旧形式の数値の場合は、自動候補を使います。初回の自動候補は得点枠が `AZ44`、年組氏名欄が `AZ48` です。この候補では幅を最大21列に調整します。手動指定ではひな形の幅を使います。
- 配置先が既存の内容と重なる場合や用紙外になる場合は、別の位置を指定します。候補の確認後に出力が変わった場合も、候補を確認し直します。
- 出力を直接編集したため登録時の状態と一致しないパーツは、アプリからの変更が止まります。
- 行を挿入して位置がずれたパーツは、パーツ全体が登録時の状態と一致すれば削除できます。削除候補が見つからない場合や複数ある場合は、別のセルを選び直します。
- 削除確認ダイアログが開いている間は、背後のシートを操作できません。確定前に右上の「×」で閉じた場合は、パーツ編集画面に表示される「確認画面を閉じた場合はこちら」で確認を取り消せます。処理開始後に閉じても削除処理は続き、パーツ編集の操作は結果確認まで待機します。
- 配置や削除で10秒以上かかる案内が出た場合は、結果を待ちます。完了時に表示される応答時間の目標は3.5秒です。
