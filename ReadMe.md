# update-main.sh

`backend`、`frontend`、`common` を Git リポジトリのルートディレクトリ名として扱い、それぞれのローカルの `main` ブランチを `origin/main` から更新するスクリプトです。

## 前提条件

- macOS または Linux で Bash と Git が使えること
- `update-main.sh` と対象リポジトリが対象のディレクトリ内にあること
- 各リポジトリにローカルの `main` ブランチと `origin` リモートがあること

```text
workspace/
├── update-main.sh
├── backend/
├── frontend/
└── common/
```

対象のディレクトリ名は、スクリプト内の `TARGET_REPO_DIR_NAMES` に記載された順番で処理します。対象を変更する場合は、この配列を編集してください。

## 実行方法

```bash
./update-main.sh
```

実行場所にかかわらず、スクリプトが置かれたディレクトリを基準に対象を探します。

## 処理内容

各リポジトリについて、Git リポジトリの状態、ローカルの `main`、`origin`、作業ツリーの変更を確認します。ステージ済みまたは未ステージの変更がある場合、そのリポジトリの更新を行いません。未追跡ファイルだけの場合は処理を続けます。

確認後、必要なら現在のブランチから `main` に切り替え、`git pull origin main` を実行します。更新に成功した場合は、次のリポジトリを処理する前に元のブランチへ戻ります。更新やブランチ切り替えに失敗した場合も、残りのリポジトリの処理を続けます。

`pull` に失敗した場合、通常の処理では元のブランチへ戻しません。結果一覧で終了時のブランチを確認してください。元の作業ブランチへ `main` の変更を取り込む操作も自動では行いません。

## 実行結果

最後に成功・失敗の件数、各リポジトリの更新結果、ブランチの復帰状況を表示します。

- 終了コード `0`：すべての対象で更新と必要なブランチ復帰に成功
- 終了コード `1`：対象一覧が空、または少なくとも1件失敗
- `Ctrl+C` などで中断した場合：必要なブランチ復帰を試み、処理結果を表示
