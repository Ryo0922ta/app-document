## 要件

```markdown
図書館で本の貸し借りを管理したい。
```

## エンティティ

```markdown
【ユーザー】..利用者情報
【本の在庫】..図書館で管理している本の情報
【貸出履歴】..その本がどれくらい貸し出されたか
【ジャンル】..本のジャンル
```

## テーブル間の関係性(概要)

```markdown
users (1) ←→ (多) loan_history
stocked_books (1) ←→ (多) loan_history
genres (1) ←→ (多) stocked_books
```
